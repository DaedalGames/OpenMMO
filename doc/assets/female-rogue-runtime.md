# 여성 로그 런타임

2026-10-27. 캐릭터 생성 화면에서 여성 로그를 고르면 여성 공통 몸체에
새 로그 상의·치마·반장갑·부츠와 가터를 착용한다. 금발 단발을 사용하고 투구는 없다.
생성 화면·캐릭터 선택창·게임은 공통 모델 선택 함수에서 여성 모듈형 모델을 사용한다.
NPC는 기존 모델 선택 규칙을 유지한다.

## 원본과 런타임 출력

`node tools/prepare-female-knight.mjs`로 기존 여성 파츠와 같은 방식으로
텍스처를 WebP로 압축하고 `client/public/models/characters/modular_female/`에 저장한다.
원본 메시·UV·리그·앉기 모프와 피부 가림 정보를 보존한다.

| 파츠 | 확정 원본 | 런타임 파일 |
| --- | --- | --- |
| 상의 | [상의 v6](modular-female-rogue-top.md) | `rogue_top.glb` |
| 치마·벨트 | [치마 v6](modular-female-rogue-skirt.md) | `rogue_bottom.glb` |
| 반장갑 | [장갑 v1](modular-female-rogue-gloves.md) | `rogue_gloves.glb` |
| 부츠 | [발목 재리깅 v5](modular-female-rogue-boots.md) | `rogue_boots.glb` |
| 가터 | [가터 v1](modular-female-rogue-garters.md) | `rogue_garters.glb` |

출처·라이선스·편집용 Blender는 각 원본 문서를 따른다. 신규 생성 요청은 없다.
입출력 해시는 [런타임 제작 기록](female-knight-runtime-sources.json)에 저장한다.

### 치마 전송량 최적화 — 2026-10-28

`rogue_bottom.glb`의 베이스 컬러를 원본에서 1024×1024 WebP q94로 생성한다.
기존 2048×2048 출력과 비교해 GLB는 1,438,144 → 686,804바이트,
gzip level 6은 1,331,249 → 579,681바이트(56.5% 감소)다.
메시 압축은 gzip 전송량 절감이 작아 적용하지 않았다.
재생성 명령은 `node tools/prepare-female-knight.mjs --part rogue_bottom`이다.
14개 accessor의 값과 GLB 구조, 나머지 텍스처 2장의 바이트가 기존과 같고,
여성 캐릭터·단검 테스트 16개가 통과했다. 동일 카메라와 조명의 단독 모델 확대 화면에서
최적화 전후를 비교했다. 게임 화면에서의 비교는 아직 하지 않았다.
게임용 바이너리는 Hugging Face에 게시하고 `assets.lock`에 고정했다.

로그 장비 모델 경로에 맞춰 각 파츠를 선택하고, 치마와 부츠를 함께 착용할 때만 가터를 표시한다.
기존 여성 부츠별 동작 베이크에 로그 부츠를 추가해 발 자세·접지를 전환한다.
피부 가림과 검은 속옷 보정은 캐릭터마다 분리하며 해제·폐기 시 복원한다.
속옷 색상·거칠기·금속성 보정은 WebGPU용 노드 재질로 적용한다.

## 기본 장비

여성 로그도 신규 생성 시 시작 장비 네 부위를 착용한다.
`female_rogue_starter_outfit_20261027` 마이그레이션은 기존 여성 로그에 빠진 시작 장비를
중복 없이 지급하고 비어 있는 슬롯에만 착용한다. 보유 장비의 강화 수치와 이미 착용한
다른 장비를 보존하며 등록 NPC는 제외한다. 완료 기록을 남겨 재실행하지 않는다.

## 검수

- 실제 `CharacterCreateScene`을 WebGPU로 렌더링해 전신·얼굴 확대를 확인했다.
  로컬 DB의 신규 여성 로그와 실제 장착 정보를 `CharacterSelectScene`에 넣어
  새 복장 전 파츠가 표시되는 것을 확인했다.
  여성 기사와 로그를 두 차례 교체하고 남성→여성 전환 후 복장 복원을 확인했다.
  페이지 오류·콘솔 오류·리소스 실패는 0개다.
- 표시 삼각형은 몸체 11,657, 눈·속눈썹 등 1,376, 헤어 2,436,
  상의 3,751, 치마 2,710, 부츠 4,210, 장갑 2,350, 가터 768로 합계 **29,258**개다.
  숨김 포함 조립 합계는 **38,400**개다. 무기·망토는 포함하지 않는다.
  얼굴 형상은 원본 그대로이며 기존 머리 가중치 영역 5,057개·앞 얼굴 추정 3,489개를 유지한다.
- 여성 모델·장비 테스트와 기존 캐릭터 모델 테스트 35개를 통과했다.
  로그 전 파츠 착용, 가터 조건, 혼합 부츠, 가림 복원·캐릭터 분리·폐기를 검사한다.
- `npm run check`, `npm run lint`, `cargo fmt`, `cargo check`를 통과했다.
- 서버 인증 테스트 33개를 통과했다. 여성·남성 로그 신규 장비 지급, 기존 캐릭터의 장비 재사용·누락 지급,
  빈 슬롯 착용·기존 장비와 강화 보존·중복 실행 방지를 검사한다.

이번 화면 검수는 생성·선택 화면의 대기 자세를 대상으로 한다. 전체 게임 동작·혼합 의상의
관통 검수를 새로 수행한 것은 아니며 원본 제작 문서에 적힌 검증 범위를 따른다.

## 기본 철검 손잡이 보정 — 2026-10-27

강철 장검 제작용 손 보정값을 기본 철검에도 적용해 손잡이가 손에서 떨어져 있었다.
기본 철검 메시에는 약 7.2cm의 Y 오프셋과 4.8cm의 Z 오프셋이 남아 있으므로,
여성 손의 부착 위치를 검 모델별로 분리했다. 기본 철검은 손 본 기준
`(0.0652, 0.0422, -0.0282)`m, 강철 장검은 기존 `(0.0504, 0.1152, 0.0198)`m를 사용한다.
회전은 기존 Z 0.2rad를 유지한다. 제작용 프리뷰도 강철 장검 보정값을 명시해서 사용한다.

실제 철검·강철 장검 GLB의 손잡이 단면과 구부린 네 손가락의 거리를
대기·걷기·달리기에서 검사했다. 캐릭터 선택 화면의 WebGPU 손 확대 검수에서
기본 철검 손잡이가 손 안에 놓이는 것을 확인했다. 페이지·콘솔 오류는 0개다.

## 도적 시작 단검 — 2026-10-27

남녀 도적은 기본 철검 대신 `worn_dagger`(낡은 단검)를 지급·장착한다.
일반 단검과 같은 기존 모델·아이콘·1d4 피해를 사용하며 가격은 없고 거래할 수 없다.
기존 `dagger`의 출처·라이선스를 그대로 따르며 새 이미지·모델은 만들지 않았다.
단검 분류를 유지하므로 처음부터 연속 베기를 사용할 수 있다.

`rogue_starter_dagger_20261027` 마이그레이션은 기존 도적에게 중복 없이 지급한다.
기본 철검은 강화 수치를 보존해 가방에 남기고 단검을 장착한다.
빈 주무기 슬롯도 채우지만 다른 장착 무기는 교체하지 않는다. 등록 NPC는 제외한다.
완료 기록이 있으면 다시 지급하지 않는다.
생성·선택 화면과 게임의 단검 위치를 공유하며 여성 손에도 별도 피팅한다.
평타 찌르기의 제작·검수는 [애니메이션 기록](animation.md#dagger-basic-thrust-2026-10-27)을 따른다.
