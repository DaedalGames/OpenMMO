## 피팅과 리깅

기준은 `assets/modular_human_male_01/fitted/base.glb`, 리그 `human_male_01_mixamo_candidate_v2`, 연결부 후보 `interfaces/v1`이다. 본 계층·기준 자세·inverse bind 행렬이 공통 몸체와 정확히 일치한다. 몸체 원본은 변경하지 않았다.

몸통과 소매를 독립 정렬하고 피부 표면 여유를 확보했다. 망토와 조끼의 겹침을 보정했으며, 가죽 몸통은 팔에 끌려가지 않도록 척추 가중치를 사용한다. 뒤 망토 중앙은 아래 가죽층의 가중치를 참조한다. 손목은 같은 쪽 팔뚝·손의 표면 가중치를 전사하고, 아래 옷자락은 골반과 같은 쪽 허벅지를 따라 움직인다. 분리된 잠금 장식은 각 장식 내부에서 같은 가중치를 사용한다.

원본에서 목과 손목의 착용 공간을 막던 안쪽 면 **134개**를 정리했다. 최종 상의는 **5,201삼각형**이다. 수치 목표에 맞추기 위한 데시메이션은 하지 않았다. 제거한 면 인덱스, 정렬값, 단면 보정과 동작 보정은 피팅 명세에 남겼다. 유지한 면의 인덱스·UV와 내장 텍스처 바이트가 원본과 일치하는지 검사한다.

Blender 파일에는 공통 리그, 피팅 상의, 기존 크롭 헤어·천 바지, 숨긴 Tripo 원본과 게임 동작 표본을 포함한다. 타임라인은 연속 애니메이션이 아니라 `REST`와 표본 자세의 고정 키프레임이다. 미리보기의 천 바지는 착용 맥락용 기존 자산이다.

## 검증 범위

- 기존 `bindModularPart`와 수정된 공통 애니메이션으로 대기·걷기·달리기·점프·베기·전투 대기·앉기 **7종 × 13시점 = 91자세**를 검사했다.
- 정점 좌표·가중치가 유한하고, UV 이음의 동작 중 틈은 0이다. 최대 가중치 합 오차는 약 `1.2e-7`이다.
- 손목별 3개 단면, 단면당 64방향으로 **546개 동작 단면**을 검사했다. 커프와 같은 쪽 팔만 비교해 지나가는 옷자락을 손목으로 오인하지 않는다. 최종 최소 여유·누락·음수 개수는 단면 검증 기록의 `wrist_motion_summary`에 보관한다.
- 기준 자세 목·허리·손목 단면에서 음수 여유는 없다. 목깃의 열린 부분은 닫힌 단면으로 강제하지 않았다. 허리 단면의 피부 여유는 최소 약 5.4mm다.
- 공격 자세의 손목 간섭은 해당 자세의 스키닝 변환을 역으로 적용해 국소 보정했다. 이 보정에 사용한 포즈·몸체·애니메이션 해시를 기록했다.

기준 자세와 커프 확대는 몸통·팔·목 피부를 남겨 검사한다. 동작 그림과 Blender 검수 장면에는 상의가 덮는 몸통·상완의 피부 가림을 적용했다. 아래 미리보기 연결에서 같은 범위를 착탈 가능한 런타임 가림으로 추가했다. 원본 몸체 파일은 변경하지 않았고 손과 팔뚝은 유지했다.

이 결과는 피팅·리깅 결과이며 모든 연속 프레임의 천 충돌이나 다른 바지·장갑·투구와의 혼합 호환을 보장하지 않는다. 망토는 기존 본으로 움직이며 별도 천 시뮬레이션은 없다. 숫자상 유한 좌표·이음 검사는 전체 시각 검수를 대신하지 않는다.

예산은 몸체 13,891 + 크롭 헤어 934 + 상의 5,201 = **20,026삼각형**이며 숨긴 영역을 포함한다. 미리보기 천 바지 2,556개까지 포함하면 22,582개다. 원래 얼굴 배분 1,505개는 유지했다. 바드 하의·장갑·부츠·악기까지 완성한 세트의 예산과 실제 표시 삼각형 수는 별도로 집계한다.

## 재현

### 캐릭터 미리보기 연결 — 2026-10-10

개발 서버의 `/modular-character-preview.html?outfit=bard`에서 바드 상의와 기존 천 바지를 바로 착용한다. 상의 선택의 `바드 조끼·케이프 상의` 또는 `바드 상의 입기` 버튼으로도 선택한다. 게임 아이템·시작 장비 등록은 별도다.

Vite의 `top_bard` 경로로 피팅 GLB를 제공하고 공통 `bindModularPart`로 연결한다. 상완을 숨기고, 몸통 피부는 앞쪽 Y≤1.08m에서 뒤쪽 Y≤1.16m로 완만하게 이어지는 경계, 목 피부는 Y≥1.54m 및 |X|≤0.075m만 남긴다. 상의를 벗거나 교체하면 원래 피부가 복원되며, GLB 로딩 실패 시 선택을 비활성화하고 피부를 숨기지 않는다.

브라우저에서 표시·착탈·재착용·재부착·걷기·달리기·점프·베기·앉기 전환과 에셋 로딩 실패 처리를 확인했다. 페이지 오류는 없었다. `npm run check`, `npm run lint`, 복장·가림·캐릭터 모델 관련 테스트 100개가 통과했다. 미리보기의 가림 후 지오메트리 집계는 조합 20,687 / 표시 15,339삼각형이며, 위 원본 GLB 합계와 집계 기준이 다르다. 다른 세트 장비와의 혼합 조합은 아직 검수 중이다.

### 속옷 조합의 후면 옷자락 보정 — 2026-10-10

**[미사용] 초기 옷자락 변형과 아래 캡처는 판금과 동일한 25mm 보정으로 교체됐다.** 몸통·다리 경계와 허리 가림 수정은 유지한다.

사용자 후면 캡처에서 속옷이 초록 옷자락을 뚫고 나오고 허리 아래가 비는 현상을 재현했다. 바드의 몸통 가림이 기존 `underwear_seat` 보정을 덮어쓰던 문제를 수정해 몸통·다리 경계를 연속으로 유지한다. 후면 몸통 가림 높이를 1.16m까지 남겨 조끼 아래 빈틈을 막는다.

속옷 선택 시 뒤 옷자락에만 `bard_underwear_hem` 변형을 적용한다. 뒤쪽으로 최대 45mm 여유를 주고 안쪽 가장자리를 좌우 최대 55mm씩 벌리되, 위쪽 1.05–1.17m와 옆쪽 |X|=0.16–0.29m 구간에서 점진적으로 줄인다. 앞면·소매·상부의 좌표와 변경하지 않은 정점의 노멀은 유지한다. 바지를 다시 입거나 상의를 벗으면 원본 지오메트리로 복원한다. 초기 뒤쪽 30mm 변형만으로는 전투 대기·앉기에서 모서리 간섭이 남았다. 본 가중치 변경 시도도 충분하지 않아 폐기하고 최종본은 원래 리깅을 유지한 채 옷자락 간격을 보정했다.

이것은 미리보기의 속옷 조합용 런타임 변형이며 저장된 GLB·Blender를 변경한 것은 아니다. 기존 피팅 보고서는 원본 GLB 기준이다. 몸통·다리 경계 일치와 하의 교체 시 복원을 회귀 테스트로 확인했다. `npm run check`, `npm run lint`, 관련 테스트 101개 통과. 7종 동작의 40% 시점과 앞·뒤·옆 확대를 확인하며 모든 연속 프레임의 충돌 합격으로 해석하지 않는다.

### 판금 바지 조합의 최소 여유 보정 — 2026-10-10

사용자가 후면 판금의 돌출을 제보하면서 크게 띄우지 말고 최소한으로 조정하도록 요청했다. 판금 바지가 실제 표시될 때만 `bard_plate_hem`을 적용한다. 뒤 옷자락 Z 방향을 최대 25mm 옮기며 X·Y 좌표는 유지한다. 속옷용 좌우 벌림은 적용하지 않는다. 35mm → 25mm → 15mm를 비교했고 15mm에서 대기 자세의 돌출이 다시 나타나 25mm로 채택했다. 상부·옆면으로 갈수록 기존 마스크로 이동량이 줄어든다.

대기 자세의 요청 부위와 앞·뒤·옆 실루엣을 확인했다. 7종 동작 40% 시점도 확인했으나 전투 대기의 작은 간섭과 앉기의 판금 관통은 남는다. 최소 이동 요청에 맞춘 대기 자세 보정이며 모든 자세의 충돌 해결로 기록하지 않는다. 원본 GLB·리그·판금 바지는 변경하지 않았다.

판금 파츠 미로딩 시 미적용, 다른 하의로 교체 시 복원, 좌우 폭 유지와 최대 25mm 이동을 회귀 검사했다. 타입 검사·린트·관련 테스트 101개가 통과했다.

### 속옷·판금 보정 통합 — 2026-10-10

사용자가 판금 조합의 작은 보정을 속옷에도 사용하도록 요청했다. 두 조합 모두 `bard_rear_hem`으로 뒤쪽 최대 25mm, 좌우 이동 0의 동일한 지오메트리를 사용한다. 이전 속옷 전용 45mm 후방 이동·55mm 좌우 벌림은 제거했다. 몸통·다리 경계의 속옷 보정과 후면 허리 가림은 유지하며 천 바지는 원본 상의 형태로 복원한다. 속옷에서 판금으로 바꿀 때 같은 보정 지오메트리를 재사용하는 회귀 검사를 포함해 관련 테스트 79개가 통과했다. 이는 작은 실루엣 보정의 공유이며 동작 중 모든 관통을 해결한 것은 아니다.

### 바바리안 하의 조합 — 2026-10-10

사용자 후면 캡처의 모피 하의와 겹치는 부분에 같은 `bard_rear_hem` 보정을 연결했다. 바바리안 하의 파츠가 표시될 때만 뒤쪽 최대 25mm 이동하며 좌우 폭은 유지한다. 바바리안 하의의 모피·가죽띠 물리나 원본 지오메트리는 변경하지 않는다. 천 바지로 교체하거나 하의 파츠가 없으면 원본 상의 지오메트리를 복원한다. 속옷·판금·바바리안 선택은 동일한 보정 지오메트리를 재사용한다.

앞·뒤·옆 확대에서 요청한 후면 겹침 감소를 확인했다. 앞쪽 벨트와 옆 모피 및 큰 동작의 모든 간섭까지 해결한 것은 아니다. 하의 교체·로딩 실패 시 복원 검사를 포함한 관련 테스트 79개 통과.

캡처에 따라, 원시전사 하의가 실제 표시될 때 `bard_caveman_hem`을 적용한다. 기존 뒤쪽

교체하거나 상의를 해제할 때 복원, 보정 지오메트리 재사용을 포함한 관련 테스트 79개가
통과했다. 7종 동작 캡처와 재장착에서 브라우저 오류가 없었으며 모든 자세의 무관통 보장은 아니다.

### 피팅 재생성

저장소 루트에서 실행한다. 최초 실행은 기준 피팅 후 동작 포즈를 추출하고, 그 포즈로 손목을 보정한다.

```sh
.venv/bin/python tools/fit-tripo-bard-top.py
node tools/validate-tripo-rogue.mjs --directory assets/modular_human_male_01/bard/tripo_top_v1 --part top_bard --report doc/assets/modular-bard-tripo-top-animation-v1.json
.venv/bin/python tools/fit-tripo-bard-top.py --refine-motion
node tools/validate-tripo-rogue.mjs --directory assets/modular_human_male_01/bard/tripo_top_v1 --part top_bard --report doc/assets/modular-bard-tripo-top-animation-v1.json
.venv/bin/python tools/validate-tripo-bard-top.py
blender -b --python-exit-code 1 --python tools/blender-scripts/review_tripo_bard_top.py
```

이미 포즈 파일이 있으면 `--refine-motion` 단계부터 재생성할 수 있다. 새 모델을 만든 뒤에는 모델 해시를 참조하는 동작 검사와 Blender 렌더도 갱신한다. 피팅은 프로젝트 Python, 편집본·검수 렌더는 Blender 5.2.0 LTS를 사용했다.

## 실패와 보정

1. 초기 정렬에서 망토와 셔츠가 겹치고, 소매 끝에 옷자락용 골반 가중치가 섞였다. 뒤 망토와 소매의 영역을 나누고 옷자락 분류를 몸통 폭 안으로 제한했다. 커프가 같은 쪽 팔 본만 사용하는지 별도 검사한다.
2. 손목 단면의 큰 음수 여유는 안쪽 막힌 면 때문이었다. 반지름만 늘린 시도는 커프와 목깃에 돌출을 만들어 폐기했다. 착용을 막는 면을 먼저 정리한 뒤 바깥 실루엣과 목깃 테두리를 유지했다.
3. 공격 후면에서 가죽 등판이 팔을 따라 들렸다. 가죽의 팔 가중치를 제한하고, 뒤 망토 중앙에 아래 가죽층 가중치를 적용했다. 이 과정에서 어깨 경계가 급격해지는 시도는 폐기하고, 어깨로 갈수록 점진적으로 원래 가중치로 돌아가도록 보정했다. 최종 전역 최대 모서리 신장비는 약 3.13, 각 동작의 99백분위는 최대 약 1.49다. 이 수치는 천 관통 합격 판정이 아니라 변형 진단이다.
4. 극단 공격 자세의 작은 손목 간섭은 국소 동작 보정으로 정리했다. 원본과 최종 파일을 보존하며 중간 GLB·Blender는 별도 보관하지 않는다.
